PROPOSED SOS LOGIC

A layered response when every second matters.

The actual calling and messaging sequence will depend on the future mobile application and device implementation. The proposed design separates trusted contacts from government emergency services.

01

SOS Triggered

Wearable sends the emergency event to the connected phone.

02

Emergency Service

03

04

IMPORTANT

Emergency contacts should support, not replace emergency services.

The wearable is intended to make it easier to start a safety response. In an immediate emergency, the user should use the appropriate official emergency service.

Trusted contacts are configured by the user. The final mobile application can allow the user to add, edit and verify these contacts.
